    Ubuntu20.04安装ROS1

    tips

    所有指令的输入不需要全部敲，只用输入前几个字母再按Tab就会自动补齐或列出可选项

    1.Ubuntu20.04桌面安装

    1.1 换源

    使用MobaXterm远程连接上树莓派以后

    输入指令 

    sudo vim /etc/apt/sources.list

    会弹出以下内容

    按i进入输入模式

    将原来的源 （前面 没有加 # 的） 前面加上“#”注释掉

    在最下面粘贴上国内的源

deb-src https://mirrors.ustc.edu.cn/ubuntu-ports/ focal main main restricted universe multiverse

    粘贴好后会是如图形式:

    粘贴上后按Esc 先输入一个冒号 : (英文输入)

    再输入 

    wq!

    按Enter退出编辑

    输入 

    sudo apt update

    这个的速度和自己网速有关

    完成后

    输入 

    sudo apt upgrade

    或输入，可跳过下面一步 （以防意外建议一步一步来查看安装是否有问题） 

    sudo apt upgrade -y

    如果是sudo apt upgrade，此时需要输入y/Y

    然后就等待更新，更新快慢和自己网速有关

    注意

    如果出现断网或别的情况就先ctrl+c 再

    sudo reboot

    重启一下 然后再

    sudo apt update

    然后再 sudo apt upgrade

    重新更新

    进行到这一步说明换源已完成

    1.2 安装Ubuntu桌面版

    输入 

    sudo apt install ubuntu-desktop

    或输入 

    sudo apt install ubuntu-desktop -y

    可跳过下面一步 （以防意外建议一步一步来查看安装是否有问题）

    如果是sudo apt install ubuntu-desktop，此时需要输入y/Y

    进行到这一步说明安装Ubuntu桌面版已完成

    1.3 安装xrdp

    输入 

    sudo apt install xrdp

    或输入 

    sudo apt install xrdp -y

    可跳过下面一步 （以防意外建议一步一步来查看安装是否有问题）

    如果是sudo apt install xrdp，此时需要输入y/Y

    完成后输入 

    sudo /etc/init.d/xrdp restart

    输入 

    sudo reboot

    重启一次

    重启后输入 

    sudo vim /usr/share/lightdm/lightdm.conf.d/50-ubuntu.conf

    并在里面添加以下内容（按i进入编辑模式）

    greeter-show-manual-login=true
allow-guest=false

    添加后按Esc 先输入一个冒号 : (英文输入)

    再输入 

    wq!

    按Enter退出编辑

    退出后输入 

    sudo reboot

    重启一次

    2. ROS安装

    2.1 设置安装源

    使用国内清华源或中科大源，我前面Ubuntu使用的就是中科大源这里也就使用中科大源了

    中科大源设置（直接复制）:

    终端输入并回车以下内容 

    sudo sh -c '. /etc/lsb-release && echo "deb http://mirrors.ustc.edu.cn/ros/ubuntu/ `lsb_release -cs` main" > /etc/apt/sources.list.d/ros-latest.list'

    清华源设置（直接复制）:

    终端输入并回车以下内容 

    sudo sh -c '. /etc/lsb-release && echo "deb http://mirrors.tuna.tsinghua.edu.cn/ros/ubuntu/ `lsb_release -cs` main" > /etc/apt/sources.list.d/ros-latest.list'

    2.2 设置Key

    终端输入并回车以下内容（直接复制）: 

    sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654

    2.3 安装

    终端输入并回车以下内容（直接复制）:

    (更新命令)

    sudo apt update

    然后终端输入并回车以下内容（直接复制）:

    (安装命令)

    sudo apt install ros-noetic-desktop-full

    注意

    由于网络原因，导致连接超时，可能会安装失败，可以多次重复调用 更新命令 和 安装命令，直至成功

    2.4 设置环境变量

    设置环境变量是为了方便每次打开新终端可以直接使用，不需要再换为root模式

    终端输入并回车以下内容（直接复制）: 

    echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc

    然后再刷新一下环境变量，命令如下

    终端输入并回车以下内容（直接复制）: 

    source ~/.bashrc

    2.5 安装构建依赖工具

    终端输入并回车以下内容（直接复制）: 

    sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential

    2.6 初始化rosdep

    第一步：

    终端输入并回车以下内容（直接复制）: 

    sudo rosdep init

    第二步：

    终端输入并回车以下内容（直接复制）: 

    rosdep update

    注意

    由于网络原因可能出现读取超时的报错，只需要重新执行第二步，直到完全初始化完成

    2.7 测试ROS1

    以上步骤都完成后即可测试ROS1

    终端输入（直接复制） 

    roscore

    后打开一个新的终端

    输入（直接复制） 

    rosrun turtlesim turtlesim_node

    回车后屏幕会出现一个新窗口是一个小海龟

    再打开一个新终端输入（直接复制） 

    rosrun turtlesim turtle_teleop_key

    回车后将鼠标停留在当前终端，使用键盘的上下左右键（不是WASD）可以控制小海龟运动

    完成

    如果小海龟按照你的控制正常运动说明ROS1已完成安装且功能正常
