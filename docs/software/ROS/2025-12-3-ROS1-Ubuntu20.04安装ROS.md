## ROS安装

### 1. 设置安装源

使用国内清华源或中科大源，我前面Ubuntu使用的就是中科大源这里也就使用中科大源了

中科大源设置（直接复制）:

终端输入并回车以下内容
```bash
sudo sh -c '. /etc/lsb-release && echo "deb http://mirrors.ustc.edu.cn/ros/ubuntu/ `lsb_release -cs` main" > /etc/apt/sources.list.d/ros-latest.list'
```

清华源设置（直接复制）:

终端输入并回车以下内容
```bash
sudo sh -c '. /etc/lsb-release && echo "deb http://mirrors.tuna.tsinghua.edu.cn/ros/ubuntu/ `lsb_release -cs` main" > /etc/apt/sources.list.d/ros-latest.list'
```
### 2. 设置Key

终端输入并回车以下内容（直接复制）:
```bash
sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654
```

![key](images/key.png)

### 3. 安装

终端输入并回车以下内容（直接复制）:

*(更新命令)*

```bash
sudo apt update
```

![rosinstall](images/rosinstall.png)

然后终端输入并回车以下内容（直接复制）:

*(安装命令)*

```bash
sudo apt install ros-noetic-desktop-full
```
!!! note "注意"
    由于网络原因，导致连接超时，可能会安装失败，可以多次重复调用 **更新命令** 和 **安装命令**，直至成功

### 4. 设置环境变量

设置环境变量是为了方便每次打开新终端可以直接使用，不需要再换为root模式

终端输入并回车以下内容（直接复制）:
```bash
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
```

然后再刷新一下环境变量，命令如下

终端输入并回车以下内容（直接复制）:
```bash
source ~/.bashrc
```

### 5. 安装构建依赖工具

终端输入并回车以下内容（直接复制）:
```bash
sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential
```

### 6. 初始化rosdep

第一步：

终端输入并回车以下内容（直接复制）:
```bash
sudo rosdep init
```

第二步：

终端输入并回车以下内容（直接复制）:
```bash
rosdep update
```

!!! note "注意"
    由于网络原因可能出现读取超时的报错，只需要重新执行第二步，直到完全初始化完成

![rosdep](images/rosdep.png)

### 7. 测试ROS1

以上步骤都完成后即可测试ROS1

终端输入（直接复制）
```bash
roscore
```

后打开一个新的终端

输入（直接复制）
```bash
rosrun turtlesim turtlesim_node
```

![rostest1](images/rostest1.png)

回车后屏幕会出现一个新窗口是一个小海龟

再打开一个新终端输入（直接复制）
```bash
rosrun turtlesim turtle_teleop_key
```

![rostest2](images/rostest2.png)

回车后将鼠标停留在当前终端，使用键盘的上下左右键（不是WASD）可以控制小海龟运动

!!! success "完成"
    如果小海龟按照你的控制正常运动说明ROS1已完成安装且功能正常
