# 建模软件&相关教程

## 1.建模软件

建模软件有很多，推荐使用**SolidWorks**，实验室用的最多，有问题也最方便找前辈解决

### 1.1下载方式

下载：微信公众号“软件管家”进行搜索下载

### 1.2 更新方式

旧版本无法打开新版本文件，有的好的开源的结构如果用到新版的，此时就需要更新版本

#### 1.2.1 删除方式

参考：[SolidWorks完全卸载指南](https://zhuanlan.zhihu.com/p/391982529)

删除完后再去下载新版即可
